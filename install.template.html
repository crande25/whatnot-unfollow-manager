Whatnot Unfollow Manager

Version {{VERSION}} · Firefox add-on

A Firefox add-on for whatnot.com. Star the accounts you want to keep following, and it unfollows everyone else for you, one account at a time, while you watch.

This is an add-on for Firefox on a computer. Open this page there to install it.

Install it

Add to Firefox
  1. Click Add to Firefox. Firefox asks twice: first whether this site may install add-ons, then whether to add Whatnot Unfollow Manager. Allow both.
  2. Optional: to keep its toolbar button in view, open the Extensions menu (the puzzle-piece icon), click the gear next to Whatnot Unfollow Manager and choose Pin to Toolbar.

Needs Firefox 140 or later on a computer. The add-on is signed by Mozilla, and Firefox installs new versions from this site by itself.

Version {{VERSION}} is waiting for Mozilla's signature, which Firefox needs before it keeps an add-on installed. The install button appears here once it's signed.

Try it now, until Firefox restarts
  1. Download the source code and extract the zip.
  2. In Firefox, open about:debugging#/runtime/this-firefox and click Load Temporary Add-on…
  3. Pick manifest.json in the extracted folder.

Firefox removes a temporary add-on when it quits. Your keep list stays saved, so loading it again picks up where you left off.

Use it

  1. Go to whatnot.com and sign in.
  2. Click the round yellow button in the bottom-left corner. The add-on's toolbar button and Alt + Shift + U open the panel too, from any tab.
  3. The Following tab lists everyone you follow. Click ☆ Keep on each account you want to keep following. To keep many at once, type in the filter box and click Keep all N shown.
  4. Click Unfollow N accounts, then Yes, unfollow. Keep the tab open while it works. You can carry on browsing Whatnot in it, and Firefox asks before you close it mid-run.

Before your first big run, press Stop after one or two accounts and check on Whatnot that they're gone. Then click Reload list and run it for real.

The keep list

  • Accounts on it are never unfollowed. Each account is checked again just before it's unfollowed, so starring one mid-run still protects it.
  • The Keep list tab shows every kept account, including ones you don't follow right now. Add one by @username or profile link, or remove one.
  • Accounts are matched by Whatnot's account number, so a kept account stays kept when it changes its username.
  • It's saved in Firefox, survives restarts and Whatnot sign-outs, and all your Whatnot tabs share it. Firefox deletes it when you remove the add-on, so click Export to save a copy first. Import reads that file back, or a plain list with one username or profile link per line.

How a run works

  • It unfollows one account at a time with a short random pause after each, so 500 accounts take about 17 minutes at the default Normal speed. Careful is slower and Fast is quicker; choose in the Options tab.
  • Pause, Resume and Stop work at any time. If a run is stopped or cut short, reload the list and start again: accounts already unfollowed are no longer on it.
  • If Whatnot rate-limits it or has a server error, it waits 30 seconds, then 60, then 120 before giving up on that account. It stops by itself when you're signed out, when Whatnot refuses its requests, or after 5 failures in a row.
  • Failed accounts are marked with the reason, and Retry tries them again. Undo in the Options tab follows the accounts from your last run again.

If something goes wrong

  • Not signed in to Whatnot: sign in on whatnot.com, then click Check again.
  • The add-on could not talk to the page: reload the Whatnot tab. Tabs that were open before the add-on was installed or updated need this once.
  • No round button on Whatnot: check that Options → Launcher is on, and that the add-on may run on whatnot.com: about:addons → Whatnot Unfollow Manager → Permissions.
  • A "Performing security verification" page: that's Whatnot's bot check. Let it finish, then reload.
  • Rate limits, or it stopped after several failures: wait a while, switch to Careful, and run it again.

Limits

  • It relies on how the Whatnot website works today. If Whatnot changes it, the add-on may stop working until it's updated.
  • It's made for Firefox on a computer. Other browsers can't install it, and it hasn't been tried on Firefox for Android.
  • It changes only whom you follow. It doesn't remove followers, block anyone, or touch anything else on your account.

It runs in your browser with your existing Whatnot sign-in, talks only to whatnot.com, and collects no data. Firefox checks this site once a day for a newer version. It is unofficial and not affiliated with Whatnot.
